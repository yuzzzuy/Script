## Sub-Store Node Renamer

- 脚本：`sub-store/node-renamer/rename.optimized.js`
- 参数说明：`sub-store/node-renamer/README.md`
- Raw URL：`https://raw.githubusercontent.com/yuzzzuy/Script/refs/heads/main/sub-store/node-renamer/rename.optimized.js`

本脚本用于统一 Sub-Store 节点名称，支持国家/地区识别、倍率、线路、协议类型、能力标签、属性标签、排序和编号。

## Sub-Store Subscription Suffix Renamer

- 脚本：`sub-store/subscription-suffix-renamer/rename.js`
- 参数说明：`sub-store/subscription-suffix-renamer/README.md`
- Raw URL：`https://raw.githubusercontent.com/yuzzzuy/Script/refs/heads/main/sub-store/subscription-suffix-renamer/rename.js`

本脚本用于给 Sub-Store 节点名追加订阅来源后缀，后缀格式统一为 `[后缀]`，支持固定后缀和按订阅名映射后缀。
